## ၁. m-MNCH Care ဆိုတာ ဘာလဲ?

**m-MNCH Care** သည် ကျန်းမာရေးဝန်ကြီးဌာန၏ **မိခင်နှင့်ကလေး ကျန်းမာရေး** အက်ပ်ဖြစ်ပါသည်။ ကိုယ်ဝန်ဆောင်ချိန်မှ မွေးဖွားချိန်၊ မွေးကင်းစ၊ မွေးပြီးမိခင် ပြုစုမှု၊ ကာကွယ်ဆေးအထိ လူနာတစ်ဦး၏ ခရီးစဉ်ကို **တစ်နေရာတည်း** မှတ်တမ်းတင်နိုင်ပါသည်။

**App သည် မဟုတ်ပါ:**
- ဆေးခန်းဆုံးဖြတ်ချက်အစား မဟုတ်ပါ
- Facebook / Viber လို chat app မဟုတ်ပါ
- သင်မဖြည့်ဘဲ အလိုအလျောက် မှတ်တမ်းမတင်ပါ — **Save မလုပ်ရင် မှတ်တမ်းမရှိပါ**

## ၂. ဒစ်ဂျစ်တယ် လုံခြုံရေး — မမေ့ရသော စည်းမျဉ်း ၆ ချက်

| # | စည်းမျဉ်း | ရှင်းလင်းချက် |
|---|-----------|----------------|
| ① | **Password မပေးပါနှင့်** | အထက်လူ၊ IT၊ မိသားစု ဘယ်သူ့ကိုမှ မပေးပါ |
| ② | **လူနာအကြောင်း မမျှဝေပါနှင့်** | Viber၊ Facebook၊ ကိုယ်ပိုင် chat တွင် မတင်ပါ |
| ③ | **အလုပ်ပြီး Logout ထွက်ပါ** | မျှသုံးဖုန်းတွင် အထူးသတိထားပါ |
| ④ | **စူးစမ်းကြည့်ရန် မဖွင့်ပါနှင့်** | လူနာအလုပ်အတွက်သာ app ဖွင့်ပါ |
| ⑤ | **App / browser data မဖျက်ပါနှင့်** | Sync မလုပ်ခင် ဖျက်ရင် မှတ်တမ်းဆုံးနိုင်ပါသည် |
| ⑥ | **မျှသုံးဖုန်းတွင် Keep me logged in မခြစ်ပါနှင့်** | ကိုယ်ပိုင်ဖုန်းတွင်သာ ခြစ်ပါ |

### Password အကြံပြုချက်များ

**ကောင်းသော password:** အင်္ဂလိပ်အက္ခရာ + ဂဏန်း + သင်သိသော စကားလုံး (ဥပမာ `MaHla*1985`)  
**မကောင်းသော password:** `123456`၊ `password`၊ ဖုန်းနံပါတ်、`midwife1`  
**မလုပ်ပါနှင့်:** ဖုန်းအပေါ်တွင် password စာတမ်းကပ်ထားခြင်း  

- Password မေ့ပါက → **Admin / focal person** ကိုဆက်ပါ  
- အခြားသူ၏ login ဖြင့် ဝင်ခြင်း → **မလုပ်ပါနှင့်** (တာဝန်ယူမှု နှင့် လုံခြုံရေး ချိုးဖောက်ပါသည်)  
- မှားယွင်းစွာ အကြိမ်များစွာ ရိုက်ပါက → အကောင့် **lock** ဖြစ်နိုင်ပါသည် · ဆက်မရိုက်ဘဲ admin ကိုဆက်ပါ  

### လူနာ အချက်အလက် လုံခြုံရေး

| အခြေအနေ | လုပ်ရမည် |
|----------|-----------|
| လူနာအကြောင်း မေးမြန်းခြင်း | တာဝန်ရှိ ဝန်ထမ်းများနှင့် သာ ဆွေးနွေးပါ |
| မိသားစ်က ဖုန်းတွင် ကြည့်ခွင့်တောင်း | ဆေးရုံ/ဆေးခန်း မူဝါဒအတိုင်း လုပ်ပါ |
| လူများရှေ့တွင် ဖန်သားပြခြင်း | ဖန်သားကို ဘေးလှန်ပါ · မသုံးချိန် ဖုန်းသော့ခတ်ပါ |
| List တွင် ဖုန်းအချို့ ဝှက်ထားခြင်း | ရည်ရွယ်ချက်ရှိသော လုံခြုံရေး — လူနာမှတ်တမ်းထဲတွင် ပြည့်စုံစွာ ကြည့်နိုင်ပါသည် |

### ဖုန်း ပျောက်ဆုံး / ခိုးယူခံရပါက

ချက်ချင်း **အကြီးအကဲ / supervisor** ကိုအကြောင်းကြားပါ — အကောင့် ပိတ်ပေးရန် လိုအပ်ပါသည်။

## ၃. ဖုန်း အခြေခံ အသုံးပြုနည်း

| လုပ်ဆောင်ချက် | နည်း |
|----------------|------|
| **Tap (နှိပ်ခြင်း)** | လက်ချောင်းတစ်ချောင်းဖြင့် ပေါ့ပေါ့နှိပ်ပါ |
| **Scroll (ဆွဲခြင်း)** | အပေါ်/အောက် ဆွဲပါ |
| **ရိုက်ထည့်ခြင်း** | အကွက်ကို နှိပ်ပါ · keyboard ပေါ်လာပါမည် |
| **နောက်သို့** | ဖုန်း back ခလုတ် သို့မဟုတ် app ရဲ့ ← |
| **Save** | အောက်ဆုံးရှိ ခလုတ် · အောင်မြင်သည့် message ပေါ်လာသည်အထိ စောင့်ပါ |

**ကျော်လွန်:** ဖုန်းကို မှားနှိပ်လို့ မပျက်ပါ · နောက်သို့ပြန်ပြီး ထပ်လုပ်နိုင်ပါသည်။

### App ဖွင့်နည်း

- **ဖုန်းမျက်နှာပြင်ပေါ် MNCH icon** ရှိပါက → တစ်ချက်နှိပ်ပါ  
- **Browser link** သုံးပါက → Chrome / Safari မှ bookmark မှ ဖွင့်ပါ  

### Internet

- **WiFi** = ဆေးရုံ/ဆေးခန်း ကြိုးမဲ့ internet  
- **Mobile data** = SIM ဖြင့် internet (ငွေကုန်နိုင်ပါသည်)  
- Internet မရှိပါက app တွင် **Offline** ပြနိုင်ပါသည် — အချို့လုပ်ငန်းသာ ဆက်လုပ်နိုင်ပါသည်

## ၄. Login ဝင်နည်း

1. App ဖွင့်ပါ → **Login** စာမျက်နှာ  
2. **Email** ရိုက်ပါ (admin ပေးထားသော အတိုင်း အတိအကျ)  
3. **Password** ရိုက်ပါ (အကြီးအသေး သတိထားပါ)  
4. **Keep me logged in** — ကိုယ်ပိုင်ဖုန်းတွင်သာ ခြစ်ပါ (offline အတွက် လိုအပ်ပါသည်)  
5. **Login** နှိပ်ပါ  
6. ပထမဆုံးအကြိမ် → **Provider Consent** ဖတ်ပြီး သဘောတူပါ  
7. **Home** စာမျက်နှာ ပေါ်လာရပါမည်  

**မြန်မာ/အင်္ဂလိပ် ပြောင်းရန်:** Home တွင် **MM** သို့မဟုတ် **ENG** နှိပ်ပါ

## ၅. နေ့စဉ် အလုပ်အစဉ် (အရေးကြီးဆုံး)

```
လူနာရောက်လာပါက
    ↓
Home → Select Patient for Care (အရင် ရှာပါ)
    ↓
ရှိပါသလား?
    ├─ ရှိပါက → Patient Care Hub ဖွင့်ပါ (ထပ်မှတ်ပုံတင်မလုပ်ပါနှင့်)
    └─ မရှိပါက → Patient Registration မှ မှတ်ပုံတင်ပါ
    ↓
Patient Care Hub မှ ANC / LCG / PNC စသည်ဖြင့် မှတ်တမ်းတင်ပါ
    ↓
Save လုပ်ပြီး အောင်မြင်ကြောင်း စောင့်ပါ
    ↓
ရုံးဆင်းမီ Home → Sync
    ↓
မျှသုံးဖုန်း ဆိုရင် Logout
```

### သုံးကြိမ် မမေ့ရန်

1. **အရင် ရှာပါ** — မှတ်ပုံတင်မီ list တွင် ရှာပါ  
2. **သေချာစွာ Save လုပ်ပါ** — အောင်မြင်သည်အထိ စောင့်ပါ  
3. **ရုံးဆင်းမီ Sync လုပ်ပါ** — မှတ်တမ်းများ cloud သို့ရောက်စေပါ  

---

## ၆. လူနာ ခရီးစဉ် အကျဉ်းချုပ်

### မိခင်လူနာ

```
မှတ်ပုံတင် → ANC (ကိုယ်ဝန်ဆောင်) → LCG (မွေးဖွားချိန်) → Delivery Notes → PNC (မွေးပြီး)
```

### ကလေးလူနာ

```
မွေးချိန် Delivery Notes မှတ်တမ်း (အလိုအလျောက် ဖန်တီးသည်) → မွေးကင်းစ စောင့်ရှောက်မှု → ကာကွယ်ဆေး
```

**သတိ:** ကလေးကို လက်ဖြင့် မှတ်ပုံတင်ခြင်းသည် မွေးချိန် Delivery Notes မှတ်တမ်းမရှိသောအခါတွင်သာ လိုအပ်ပါသည်။

### Mommy / Baby filter

- **Mommy** = မိခင် (ANC, LCG, PNC)  
- **Baby** = ကလေး (ကာကွယ်ဆေး၊ newborn follow-up)  
- ရှာမတွေ့ပါက အခြား tab သို့ ပြောင်းကြည့်ပါ  

---

## ၇. Offline နှင့် Sync

### Internet မလိုဘဲ လုပ်နိုင်သော အချို့

- အချို့ မှတ်ပုံတင်ခြင်း  
- အချို့ ANC / PNC မှတ်တမ်း  

### Internet လိုအပ်သော အများစု

- LCG (မွေးဖွားချိန် စောင့်ရှောက်မှု)  
- Delivery Notes  
- ကာကွယ်ဆေး  
- လွှဲပြောင်းမှု (Transfer)  
- အစီရင်ခံစာများ  

**Offline ဖြစ်ပါက:** ဖုန်း duplicate စစ်ဆေးမှု မလုပ်နိုင်ပါ — **ရှာဖွေမှု သေချာစွာ လုပ်ပါ**

### Sync လုပ်နည်း (နေ့စဉ်)

1. Internet ချိတ်ပါ (WiFi သို့မဟုတ် data)  
2. **Home** သို့သွားပါ  
3. **Sync** နှိပ်ပါ  
4. အောင်မြင်သည့် message ပေါ်လာသည်အထိ စောင့်ပါ  

**မလုပ်ပါနှင့် (focal person မမေးဘဲ):** App ဖျက်ခြင်း · browser data ရှင်းခြင်း · ဖုန်း factory reset
